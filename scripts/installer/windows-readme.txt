SlintYT for Windows x64

Keep slintyt.exe and libmpv-2.dll in the same folder.
Install yt-dlp and a supported JavaScript runtime such as Deno, and make
both available on PATH before launching SlintYT. Restart the desktop session
if an installer changed PATH. A browser profile signed in to YouTube is required.

Select the browser profile in SlintYT. Firefox is supported on Windows;
Chromium App-Bound (v20) cookie encryption is not currently supported.
